# عالم لو — دليل القناة (مرجع كل الموظفين)

## الهوية
- الاسم: عالم لو — المعرّف: @AalamLawAR
- الرابط الدائم: https://www.youtube.com/channel/UC6qe-5Xe8NRusT1z2iq0LcQ
- الفكرة: قصص "ماذا لو" بالعربي برسوم العصا السينمائية، قدرة بشرية تُدفع للأقصى، ثم قسم "ما الحقيقي؟".
- الجمهور: عربي عام (أكبر الدول من بيانات القناة الشقيقة: العراق، الجزائر، مصر، المغرب، السعودية، سوريا).

## قواعد ثابتة
- السكريبت المنطوق: فصحى معاصرة بتشكيل كامل. كل ما عدا ذلك: عربي بدون تشكيل.
- صوت واحد فقط لكل الفيديوهات: Microsoft Edge TTS، الصوت `ar-SA-HamedNeural`، `--rate=+15% --pitch=-4Hz`.
  (إن توفر رصيد ElevenLabs كافٍ للحلقة كاملة يمكن استبداله بصوت "احمد النبرة العميقة الدافئة" YKGG8oefXIWbncG7wgoX — لكن لا يُخلط صوتان في حلقة واحدة أبدًا.)
- مدة الحلقة الطويلة: 8–12 دقيقة (نحو 1,200–1,700 كلمة).
- عدم اختراع حقائق أو دراسات أو اقتباسات. الخلاف العلمي يُذكر بآرائه.
- الإفصاح عن الصوت المولّد بالذكاء الاصطناعي في الوصف وفي إعداد يوتيوب.
- العناوين تبدأ بـ "ماذا لو" وتستعمل المفارقة ("... إلا ...") عند مناسبتها. تقييم vidIQ للعنوان ≥ 90.
- الصورة المصغرة: 3 عناصر فقط (وجه كبير بتعبير قوي + عنصر مفارقة واحد + كلمتان)، ألوان تحذير حمراء/صفراء، خلفية مشبعة مع عمق ضبابي، بلا فراغ زائد ولا ازدحام. الهدف ≥ 90 في vidIQ.

## جدول النشر
- حلقة طويلة يوميًا الساعة 20:00 بتوقيت مكة (17:00 UTC).
- سبب الاختيار: نشاط الجمهور العربي يبلغ ذروته بين 18:00 و24:00 بتوقيت مكة (أقوى النوافذ: الجمعة 21–24، السبت 18–21)، والنشر قبل الذروة بساعة يمنح يوتيوب وقتًا لاختبار الفيديو. 20:00 مكة = 19:00 القاهرة = 18:00 الجزائر والمغرب = 20:00 بغداد.
- يُراجع الوقت بعد 30 يومًا من بيانات قناة عالم لو نفسها.

## خط الإنتاج (الترتيب)
باحث الأفكار ← كاتب السكريبت ← المدقق ← مهندس الصوت ← المحرّك ← المدقق ← مصمم التغليف + خبير السيو ← المدقق ← جاهز للنشر ← محلل الأداء + صانع الشورتس.
أسبوعيًا: محسّن القناة (تحسين الموجود) + المطور الدائم (تطوير الاستوديو والأتمتة).
