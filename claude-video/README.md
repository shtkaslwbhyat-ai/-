# فيديو: كيف تصنع فيديو جميل عبر Claude Code

فيديو عمودي (1080×1920، مناسب لـ Reels / TikTok / Shorts) مبني بـ [Remotion](https://remotion.dev)، والتعليق الصوتي من ElevenLabs.

## المشاهد
| # | المشهد | النص |
|---|--------|------|
| 1 | **الهوك** | تخيّل إنك تسوّي فيديو احترافي كامل... بدون ما تفتح أي برنامج مونتاج. ولا ثانية! |
| 2 | الكشف | هذا الفيديو اللي تشوفه الحين؟ انصنع بالكامل عن طريق كلود كود. والصوت؟ من إليفن لابز. |
| 3 | الخطوة 1 | افتح كلود كود واكتب فكرتك |
| 4 | الخطوة 2 | السكربت + الصوت من ElevenLabs |
| 5 | الخطوة 3 | بناء المشاهد بالكود (Remotion) |
| 6 | الخطوة 4 | الرندر والنشر |
| 7 | CTA | أنت عليك الفكرة... والباقي على كلود |

## الصوت
ضع ملفات الصوت في `public/vo/s1.mp3` … `s7.mp3` — مدة كل مشهد تتكيّف تلقائياً مع طول ملفه
(إن لم يوجد الملف يُعرض المشهد صامتاً بمدة تقديرية).

```bash
ELEVENLABS_API_KEY=xxx node generate-voiceover.mjs
```

## التشغيل
```bash
npm i
npx remotion studio            # معاينة
npx remotion render ClaudeCodeVideo out/claude-code-video.mp4
```
